# TechWorks Digital Learning Lab

**Code by Tee subsidiary**

Learn. Create. Build What’s Next.

The TechWorks Digital Learning Lab platform is a project-based, offline-first technology learning ecosystem for students, instructors, families, and education partners.

## Product layers

- Public website
- Student, instructor, family, and organization experiences
- Curriculum and lesson delivery
- Tool Library
- Portfolio and opportunities
- Offline-first learning pathways
- Accessibility, safety, and permissions

## Technology

Next.js · TypeScript · Tailwind CSS

## Status

Early platform build — public experience and portal foundations are being developed from the TechWorks documentation system.
